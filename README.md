# Grid World Navigation Using Q-Learning

## Objective
To train a robot using Q-Learning to find a path from a starting point to a goal while avoiding obstacles.

## Project Description
This project demonstrates a simple Reinforcement Learning environment where a robot moves in a 4×4 grid. The robot can move up, down, left, or right and learns from rewards and penalties.

## Reward System
- Normal movement: -1
- Obstacle: -5
- Goal: +10

## Technologies Used
- Python
- Reinforcement Learning
- Q-Learning

## Result
The robot successfully learned a path from [0,0] to [3,3] while avoiding obstacles.
